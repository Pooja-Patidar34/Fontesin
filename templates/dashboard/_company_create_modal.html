{% comment %} Reusable "Add Company" modal — the create half of the Company Database modal, hosted on pages that want an in-page create flow (e.g. My Companies) without navigating to /companies/. The form submits (AJAX) to the `companies` endpoint, which is the single source of truth for company creation/validation. On success the host page is reloaded so the new row renders in that page's own row format. Required context: form, country_states, is_business_user, can_manage, and (optional) tenants / selected_tenant_id for the superuser tenant picker. Trigger by giving any element id="add-company-btn". {% endcomment %}
