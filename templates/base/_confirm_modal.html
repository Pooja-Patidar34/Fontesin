{% load i18n %} {% comment %} Reusable confirmation modal. Include once per page: {% include "base/_confirm_modal.html" %} Any
that carries a [data-confirm] attribute is intercepted on submit and routed through this modal instead of the native confirm() dialog. Supported attributes (all optional except data-confirm): data-confirm marks the form (presence is enough) data-confirm-tone "primary" (default) or "warning" — colours icon + button data-confirm-icon Font Awesome glyph, e.g. "fa-bolt" data-confirm-title heading text data-confirm-body explanatory line data-confirm-ok confirm-button label data-confirm-name an entity name shown as a chip (optional) {% endcomment %}
